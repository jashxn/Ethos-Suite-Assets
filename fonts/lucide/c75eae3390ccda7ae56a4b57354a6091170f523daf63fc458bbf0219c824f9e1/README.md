# Lucide icon font

This is an unchanged copy of the font and icon metadata from
[notpoiu/lucide-roblox-direct](https://github.com/notpoiu/lucide-roblox-direct)
at revision `04f2bbae632268b1c165b4e477340b1566606958`.

The font contains 1,866 icons. Use a canonical icon name, such as `moon`,
as the label text. The font converts the name to its icon through an
OpenType ligature.

## Files and notices

- `lucide.ttf`: generated TrueType font.
- `codepoints.json`: unchanged upstream metadata.
- `LICENSE`: Lucide ISC and Feather MIT notices.
- `LOADER-LICENSE`: upstream loader MIT notice.
- `provenance.json`: exact source revisions and file checksums.

The font SHA-256 is
`c75eae3390ccda7ae56a4b57354a6091170f523daf63fc458bbf0219c824f9e1`.
Its size is 903,264 bytes. Its Adler-32 checksum is `bc832231`.

The client generates its font family JSON from the registered local TTF
URI. That URI belongs to the client session, so a fixed font family JSON
is not included here.
